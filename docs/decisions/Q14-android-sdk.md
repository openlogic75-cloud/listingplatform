# Q14 - Android minimum / target SDK

- Status: decided (2026-09-05)
- Task: M1.2, M0.3

## Decision

Use **Flutter defaults** for the Android platform folder:

- `minSdk` 21 (Flutter default; covers the low-end device base this platform targets)
- `targetSdk` / `compileSdk`: latest Flutter stable defaults at build time
- Distribution: APK/AAB built outside Hostinger scope

## Consequences

- `mobile/android/` is generated by `flutter create .` on a machine with the Flutter SDK (see `mobile/README.md`); the Dart/lib code is committed regardless.
- Material 3 dynamic color applies on Android 12+, with the static seed scheme (brand blue) as fallback below that - implemented in `mobile/lib/core/theme/app_theme.dart`.
