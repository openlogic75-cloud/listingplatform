# Icons (not tracked)

This folder holds the Tabler SVG icons the app bundles. They are third-party
work and are **not tracked in this repository**; only this placeholder is kept
so the `assets/icons/` entry in `pubspec.yaml` stays valid.

Download the set and drop the SVG files here:

- Tabler Icons — https://tabler.io/icons
- Repository — https://github.com/tabler/tabler-icons (MIT)

Use outline icons by default and the filled variant only for active/selected
states, recoloured through `currentColor`. See `ATTRIBUTION.md` at the
repository root for the full list of excluded assets.
