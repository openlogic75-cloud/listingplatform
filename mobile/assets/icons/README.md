# Icons (not tracked)

This folder holds the Tabler SVG icons the app bundles. They are third-party
work and are **not tracked in this repository**; only this attribution file is
kept so the `assets/icons/` entry in `pubspec.yaml` stays valid.

**Source:** Tabler Icons — https://tabler.io/icons
**Repository:** https://github.com/tabler/tabler-icons
**Licence:** MIT

Icons used by the app (copy these `.svg` files into this folder):

- `building-store.svg`
- `heart-handshake.svg`
- `map-pin.svg`
- `rosette-discount-check.svg`
- `tool.svg`
- `truck-delivery.svg`
- `user-plus.svg`

Use outline icons by default and the filled variant only for active/selected
states, recoloured through `currentColor`. See `ATTRIBUTION.md` at the
repository root for the full list of excluded third-party assets.
